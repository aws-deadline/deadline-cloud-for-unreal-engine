# AGENTS.md — deadline (Python packages)

## Overview

This directory contains the Python packages for AWS Deadline Cloud for Unreal Engine. It is a namespace package under `deadline.*` with five subpackages:

- `unreal_submitter` — Job submission from the Unreal Editor (runs inside UE Python)
- `unreal_adaptor` — Worker-side adaptor that launches and drives Unreal Engine on render nodes
- `unreal_perforce_utils` — Perforce workspace management and source control operations
- `unreal_logger` — Logging utilities that bridge Python logging to Unreal's log system
- `unreal_cmd_utils` — Unreal Engine command-line argument parsing and merging

## Key dependencies

- `deadline` (client library) — job submission APIs, telemetry
- `openjd-adaptor-runtime` — adaptor framework for worker-side execution
- `openjd-model` — Open Job Description model
- `p4python` — Perforce Python bindings
- `unreal` module — only available when running inside Unreal Engine (guard with try/except)

## Versioning

Each subpackage has a `_version.py` generated by `hatch-vcs`. Do not edit these files manually.
